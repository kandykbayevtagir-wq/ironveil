A useful first pass, with explicit boundaries

Local by default

A normal scan makes no network request. Optional OSV lookup sends package coordinates only.

Masked at the source

Evidence is masked before it reaches text, JSON, SARIF, HTML, JUnit, cache, or CI summary.

Git-aware

Review staged additions, a branch range, one commit, or deliberately bounded reachable history.

Predictable policy

Stable IDs, fingerprints, severity, confidence, baselines, suppressions, and exit codes support CI.

Portable reports

Produce SARIF for Code Scanning or a self-contained HTML report for local review.

No target execution

IronVeil does not import repository Python, install dependencies, or run build scripts.

Synthetic output

Findings without the full secret

Zero configuration

Start with one command

ironveil .
ironveil staged
ironveil diff origin/main...HEAD
ironveil scan . --format html --output ironveil-report.html

What the preview checks

  • Provider-specific and contextual secret patterns, private keys, credential URLs, and high-entropy candidates.
  • Sensitive files, oversized content, generated directories, and ignore-state mistakes.
  • Python and JavaScript dependency hygiene, with explicit opt-in OSV advisory queries.
  • Explainable Dockerfile, GitHub Actions, Terraform, and Kubernetes checks.

IronVeil is not a full SAST engine, container scanner, or proof that a repository is safe. Use it as one control in a layered review process.
