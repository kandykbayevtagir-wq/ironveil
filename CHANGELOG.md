# Changelog

All notable changes to IronVeil are documented here. The project follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Initial local-first scanner architecture for bounded file discovery, masked secret findings,
  sensitive files, repository checks, and deterministic policy evaluation.
- Git-aware staged, diff, commit, and bounded history scanning.
- Baselines, expiring suppressions, declarative custom rules, and an external metadata cache.
- Text, JSON, SARIF 2.1.0, portable HTML, and JUnit reporting.
- Offline dependency hygiene checks and explicit opt-in OSV queries.
- Localhost-only report UI, GitHub Action, pre-commit hook, documentation, and Pages preview.
- Multi-version CI, CodeQL, dependency review, OpenSSF Scorecard, SBOM generation, and Trusted
  Publishing preparation.
